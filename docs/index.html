User Journey Map

5 Journeys · 5 Roles · Pain Points

Role Definitions

Roleผู้ใช้ตัวอย่างหน้าที่หลัก
CFO / AdminK. ปริญญา ส.ดูภาพรวม, อนุมัติ, Export, ตั้งค่าระบบ
Treasury ManagerK. รดา ม.จัดการ Cash, Upload Bank Statement, Forecast
AccountantK. ธนวรรธน์ ค.บันทึก GL, Import ข้อมูลบัญชี
ApproverK. พิชญา ต.ตรวจสอบ, อนุมัติรายการ
Viewer (Audit)K. สุทธิพงศ์ บ.ดูข้อมูลอย่างเดียว

Journey 1: CFO — Daily Morning Review (~15–20 นาที)

08:00  → Dashboard (CONSO) → ดู KPI 4 ตัว (Total Cash, Net CF Q1)
         → Trend Chart toggle "วัน" → ดูความผันผวน 30 วัน
         → Recent Transactions → scan สถานะ "Review"
         → Forecast → Scenario Base → ดู Min Balance 8 สัปดาห์
         → (ถ้าไม่ดี) Indirect CF → Tab 2 WC Reconcile → AR CF Impact
         → Export Center → Indirect CF Report → ส่ง Board Meeting

Pain Points: Opening balance Forecast hardcoded · ไม่มี default company last-selected

Journey 2: Treasury Manager — รับ Bank Statement (ทุกวันจันทร์ ~30–45 นาที)

Mon AM → Finance Input → Tab บัญชีธนาคาร → ดู 7 accounts
         → ปุ่ม Upload → UploadModal → Import Excel
         → Tab เงินรับ → Filter Pending → ตรวจแต่ละรายการ
         → Tab Reconcile AR → กระทบยอด AR vs Bank
         → CF Report Direct → Tab 4 → ดู ✓ ยอดตรง หรือ ⚠ มีผลต่าง
         → Export Center → Direct CF เดือนนี้ → ส่ง CFO

Pain Points: ต้องสลับ tab หลายครั้ง · ไม่มีแจ้งเตือนอัตโนมัติเมื่อ reconcile ไม่สมดุล

Journey 3: Accountant — Import GL รายเดือน (~1–2 ชั่วโมง)

สิ้นเดือน → Accounting Input → Trial Balance → Import BC Excel
           → ดู Debit = Credit (Balanced)
           → Tab ลูกหนี้ → ดู Aging buckets + Over 90 วัน
           → Tab เจ้าหนี้ → ดู Next Due Date per vendor
           → Indirect CF → Tab 0 → ตรวจ Net Profit ตรงกับ GL
           → Tab 2 WC Reconcile → ตรวจ AR/AP CF impact

Pain Points: ไม่มี Validation ว่า Trial Balance สมดุล · ต้อง Manual compare GL vs CF

Journey 4: Viewer/Auditor — Quarterly Review

ปลายไตรมาส → Dashboard → CONSO → Q1 → ดู KPI + Trend
              → Direct CF → Tab 0 (Full Statement)
              → Tab 4 → กระทบยอดเงินสด vs Bank
              → Tab 5 → Cross-validation checklist
              → Indirect CF → Tab 3 → Direct vs Indirect Difference = 0
              → Export Center → ดาวน์โหลดประวัติ

Journey 5: CFO — Board Preparation

ก่อนประชุม → Indirect CF → Tab 1 CF แยก Segment (HMW vs CLIK vs ACG)
              → Forecast → toggle Bear/Base/Bull scenarios
              → Export Center → Indirect CF + Forecast + AR Aging (3 ไฟล์)

Pain Points: ต้อง Export ทีละไฟล์ · ไม่มี Bulk Export · ไม่มี Presentation mode

START
  │

  │
  [STEP 2] กระทบยอด AR/AP
  ├── Accountant: ตรวจ AR Aging → Accounting Input → ลูกหนี้ tab
  ├── Treasury: Reconcile AR → Finance Input → Reconcile AR tab
  └── Treasury: ตรวจ AP Due → Accounting Input → เจ้าหนี้ tab
  │
  [STEP 3] ตรวจสอบ Cash Flow Statements
  ├── CFO: Direct CF → Tab 4 กระทบยอดเงินสด
  │    └── ✓ ยอดตรง → Step 4 | ⚠ มีผลต่าง → กลับ Step 1-2
  └── CFO: Indirect CF → Tab 3 Direct vs Indirect
       └── Difference = 0 → Step 4 | ≠ 0 → Settings → CF Mapping
  │
  [STEP 4] สร้าง Report
  ├── CFO: Export Direct CF + Indirect CF + Forecast
  └── Treasury: ส่ง Report → Approver Review
  │
  [STEP 5] อนุมัติ (Manual — ไม่มีใน System ขณะนี้)
  └── Approver: Tab 5 Cross-validation → Sign-off
  │
  END

Workflow 3: buildSegmentCF Algorithm

INPUT: cfData = { direct: directCF }
  ↓
ดึง cfMainCur = ยอด "เงินสดรับจากการขายสินค้าและบริการ" (current)
  ↓
คำนวณ totalIncQ1 = รวม income ทุก segment ทุก entity (Q1)
  ↓
สำหรับแต่ละ entity (HMW, CLIK, ACG):
  สำหรับแต่ละ income segment:
    pct = incQ1_segment / totalIncQ1          (สัดส่วน)
    scaledInc = cfMainCur × pct               (ยอดรับตามสัดส่วน)
    arCFImpact = -(AR change of segment)      (AR เพิ่ม → CF ลด)
    allocOpOut = totalOpOut × pct
    operatingCF = scaledInc + arCFImpact + allocOtherIn + allocOpOut
    investingCF = totalInvCF × pct
    financingCF = totalFinCF × pct
    netCF = operatingCF + investingCF + financingCF
  ↓
OUTPUT: segs[] array (14 segments × 3 entities) → แสดงใน Tab 1

Workflow 5: กระทบยอดเงินสดปลายงวด (Tab 4)

Workflow 7: Working Capital → CF Impact

AR: Change = Closing AR - Opening AR → CF Impact = -(Change)
    [AR เพิ่ม → เงินออก → CF ลด]

AP: Change = Closing AP - Opening AP → CF Impact = +(Change)
    [AP เพิ่ม → ยังไม่จ่าย → CF เพิ่ม]

Inventory: Change = Close - Open → CF Impact = -(Change)
    [Inv เพิ่ม → ซื้อมากขึ้น → CF ลด]

Accrued: Change = Close - Open → CF Impact = +(Change)
    [ค้างจ่ายเพิ่ม → ยังไม่จ่าย → CF เพิ่ม]

Total WC CF Impact = AR + AP + Inv + Accrue → Tab 2 WC Reconcile
